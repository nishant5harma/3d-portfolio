# 3d-portfolio

3D portfolio site built with Next.js, GSAP, and Three.js.

## Live site (GitHub Pages)

1. **Settings → Pages → Build and deployment**
2. Source: **Deploy from a branch**
3. Branch: **`prod`** / **`/ (root)`**
4. Save — site URL: **https://nishant5harma.github.io/3d-portfolio/**

## Deploy to `prod`

```bash
npm run deploy:prod
```

This runs a static export (`build:gh`) and force-pushes the `out/` folder to the `prod` branch.
